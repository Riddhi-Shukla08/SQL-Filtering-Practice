# SQL Filtering Practice

## 📌 Project Overview

This project is based on SQL Filtering Practice using the Northwind-style dataset.  
The main purpose of this project is to practice different SQL filtering conditions and understand how data can be selected from tables based on specific requirements.

## 🎯 Objective

- Practice SQL `WHERE`
- Understand `IN`
- Use `BETWEEN` for range-based filtering
- Practice `LIKE` for pattern matching
- Use `AND` and `OR` conditions
- Filter customer, product and order data

## 🛠️ Tools Used

- MySQL
- SQL
- Northwind-style Dataset

## 📊 Tables Used

- Customers
- Products
- OrderDetails

## 🔍 Queries Covered

A total of **12 SQL queries** are included in this project.

1. WHERE condition

4. IN with CategoryID
5. BETWEEN operator
6. BETWEEN with Quantity
7. LIKE with starting characters
8. LIKE with ending characters
9. LIKE with matching text
10. WHERE + AND
11. WHERE + OR
12. WHERE + AND + LIKE

## 💡 Key Learnings

- `WHERE` is used to filter records based on a condition.
- `IN` is useful when checking multiple values.
- `BETWEEN` is used to filter values within a range.
- `LIKE` is used for pattern matching.
- `AND` requires multiple conditions to be true.
- `OR` allows either of the conditions to be true.

## ❓ Interpretation

### LIKE vs =

`=` is used when we want an exact value match, while `LIKE` is used when we want to search for a specific pattern.

### When to use BETWEEN?

`BETWEEN` is useful when we need to filter data within a specific range, such as prices between 10 and 30.
